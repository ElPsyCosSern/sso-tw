# 3444 上櫃普通股與 0050 股票型 ETF 專屬分析

## 目標與邊界

- 本功能分支：`feat/otc-3444-etf-0050-analysis`，基於 LINE／Sheets 既有整合版本；不開新 Worker、資料庫、外部 Agent 或付費 API。
- **3444 利機（上櫃）**：沿用普通股 EPS、ROE、技術指標及歷史技術回測；額外要求近 20 交易日官方/FinMind 提供的日成交金額平均 ≥ 新臺幣 **500 萬元**。未取得可信交易金額，或低於門檻，不得 BUY。部位建議上限 5%，實際下單須檢查買賣價差及掛單深度。
- **0050 元大台灣50（股票型 ETF）**：以自己的均線、動能、波動與扣成本回測策略取代普通股 EPS／ROE 門檻。**只對 0050 啟用**；00685L、00687B 等其他 ETF 與興櫃仍維持保守防護。
- 同一張 Watchlist、Signals、Reports；LINE /分析、/觀察、/選股、/個股、/完整報告維持原有介面。
- 假日或資料日期不是台灣當日時，3444/0050 不能輸出新的 BUY，改 WATCH 並附資料時間。
- 不自動下單、不自動訂購資料服務、不修改真實持倉。

## 資料來源與查核

- **FinMind** `TaiwanStockPrice` 免費逐檔日行情：包含 date、open/max/min/close、Trading_Volume（股）與 Trading_money（新臺幣）；3444 與 0050 已在 2026-11-06 查得資料。
- 2026-11-08 的唯讀抽樣：3444 截至 2026-11-06 最近 20 日平均成交金額約 **NT$8,213,367**。這只代表歷史流動性，非限價成交保證。
- 0050 在 **2025-06-18 以 1:4 分割**；`TaiwanStockPriceAdj` 在目前不付費的查詢回傳 HTTP 400（FinMind 2026 方案頁列為 Backer）。因此本版刻意從 **2025-06-18 以後**取原始行情；不可把分割前後的價格直接串接進均線／回測。
- 資料未還原配息，績效僅為價格變化；**不是含息報酬**。不自動取得淨值、折溢價、追蹤差距與持股權重，這些在正式下單前須向投信／證交所查核。沒有資料就不製造數值。

## 0050 策略 v1：可重現、可拒絕資料不足

- 成交後條件：最近收盤 > MA20 > MA60；20 日價格動能為正；近 20 日平均成交金額 ≥ NT$500 萬；近 20 日年化波動 ≤ 45%。
- 歷史驗證：在分割後至最新資料的每個收盤日，只使用截至該日資料產生訊號；下一交易日開盤才進場，20 個交易日內遇 **-8% 停損**／**+10% 停利**則退出；同一天同時觸及兩者保守先算停損，跳空低於停損按實際開盤價。
- 交易不重疊，估計來回總成本 **0.6%**（買賣手續費、ETF 賣出證交稅與滑價的統一保守估計），不是任何人保證能取得的費率。資料不含股息、交易價差與即時折溢價，績效可能與實際投資差異很大。
- 自動 BUY **還需**至少 8 筆非重疊歷史成交、扣估計成本後勝率 ≥55% 且平均每筆淨報酬為正；任何條件不足改 WATCH。條件分數非上漲機率；歷史門檻不代表有統計顯著獲利，仍有樣本小、期間偏多及過度擬合風險。
- 0050 研究部位上限示意 **10%**；8%/10% 停損停利為風控情境，不能把當日收盤價當成次日確定成交價。
- 嚴格拒絕缺少有效 OHLC、成交金額、歷史不足、重複日期或超過 35% 的未知價格斷層；疑似新分割時先停用 BUY，核對公司行動。

## 3444 策略 v1

- 不重複新造 EPS／ROE 模型。沿用既有評分，以 `Trading_money` 檢查 20 日平均交易金額、最少 18 日有效資料。
- 未通過只將 BUY 改 WATCH，不偽造分數或回測結果。普通股歷史勝率主要是技術訊號回測，當期基本面門檻沒有逐歷史日期回推，**不能當作整套基本面策略的無前視回測**。
- 上櫃成交金額門檻（NT$500 萬）是研究用的流動性篩選值，非官方流動性規則，也不代表掛單能一次成交。

## 驗收（不寫真實 Google Sheets）

- 0050 使用合成行情：測分割前資料被排除、未來日期不污染歷史觀點、樣本不足不可 BUY、日內同時觸及停損與停利先算停損、跳空不能按理想停損價成交、報告不再誤顯 EPS 不合格。
- 3444：測達標、未達標及缺成交金額時的 BUY/WATCH 與部位上限，且其他上市股票的舊模型不受影響。
- main 路由：兩檔分流到正確策略，LINE 報告/SIGNALS 格式不改，週末過期訊號不當作新買進建議。
- Python 全部回歸測試、Node Worker 測試、前端測試及 GitHub CI；最後可用官方/FinMind 唯讀資料做 smoke test。只有 CI 與必要資料驗證通過，才允許合併與部署。
